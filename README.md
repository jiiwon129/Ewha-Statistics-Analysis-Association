# ESAA 이화통계분석학회

> 이화통계분석학회(Ewha Statistics Analysis Association) 활동 중 수행한 스터디, 과제, 미니프로젝트, 경진대회 코드를 정리한 아카이브

### YB

- `YB/스터디` — 학회 스터디 코드
- `YB/과제` — 주차별 과제
- `YB/연습문제` — NumPy·pandas·ML 등 연습문제
- `YB/수상작 리뷰` — 데이터 분석 경진대회 수상작 리뷰
- `YB/미니프로젝트` — 시각화·분류·회귀 미니프로젝트
- `YB/방학프로젝트` — 사이버 공격 유형 예측 해커톤

### OB

- `OB/과제` — 학회 과제
- `OB/연습 문제` — ML·추천시스템·시계열 등 연습문제
- `OB/수상작 리뷰` — 경진대회 수상작 리뷰
- `OB/프로젝트` — 유통데이터 활용 경진대회 등 팀 프로젝트
